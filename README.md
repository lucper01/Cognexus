# Cognexus

Cognexus est une application web de graphe de connaissances destinée à structurer un projet de recherche.

Elle permet de relier visuellement des concepts, articles, hypothèses, expériences, résultats et sections de manuscrit dans un même espace interactif.

## Fonctionnalités

- création et édition de nœuds de connaissances ;
- relations typées entre les nœuds ;
- recherche plein texte et filtres par type ;
- fiches détaillées avec résumé, statut, tags, référence, lien et notes ;
- visualisation interactive du graphe ;
- sauvegarde automatique dans le navigateur ;
- import et export de projets au format JSON ;
- mode clair et sombre ;
- installation en PWA ;
- fonctionnement compatible avec GitHub Pages.

## Stockage

La version actuelle stocke les données localement dans le navigateur. L’export JSON permet de sauvegarder ou transférer un projet vers un autre appareil.

## Déploiement

Le site est entièrement statique et peut être publié directement avec GitHub Pages depuis la branche `main`.
